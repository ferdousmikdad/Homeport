Changelog

New features and fixes in Homeport. Follow along on GitHub.

v1.3.1November 13, 2026

A real desktop app for every system

Download, install, open — Homeport now lives in its own window.

New

  • Installers: .dmg for macOS, Setup.exe for Windows, AppImage and .deb for Linux — built automatically for every release.
  • One-line terminal install for macOS, Linux and Windows.
  • The download button picks the right installer for your computer.
  • Quit Homeport in the sidebar and command palette stops Homeport and all its apps.

Improved

  • The installed app keeps your apps and logs in your user folder, so updates never touch them.
v1.2.0November 13, 2026

WordPress mode, and every project works when shared

Copies of live sites, local installs and share links — all just work.

New

  • WordPress mode: one-click database, wp-config.php (original backed up) and a live-URL helper; import .sql/.sql.gz backups.
  • Imported sites keep working on localhost, phones and share links without rewriting the database.

Improved

  • Share links and named URLs now pass the real address to apps and fix leftover localhost links in pages and redirects — so Laravel, Django, WordPress and others render correctly for visitors.
v1.1.0November 13, 2026

Nothing to install first

Download, double-click, done — on every system.

New

  • run.command, run.sh and run.bat set everything up by themselves. If your computer has no Python, Homeport downloads a private copy into its own folder — no admin rights, nothing installed system-wide.
  • Starting is instant once set up; libraries are only reinstalled when they change.

Fixed

  • macOS: no more “install developer tools” pop-up on Macs without them.
  • Ubuntu/Debian: works even when python3-venv isn't installed.
  • Quitting Homeport no longer waits on open browser tabs.
v1.0.0November 13, 2026

First public release

Homeport is now free and open source under the MIT license.

Run anything

  • Detects how to run Laravel, PHP, Django, FastAPI, Flask, Node (Vite, Next, Nuxt, Astro…), Rails, Go, Rust, Spring Boot, .NET, Docker Compose, static sites and more.
  • Project discovery: add every project in a folder at once.
  • Community recipes: support new frameworks with one JSON file (Hugo, Jekyll, MkDocs, Zola, Phoenix, Flutter web included).

Use

  • Command palette (⌘K / Ctrl K) for every action.
  • Named URLs like http://shop.localhost:7777, with live reload.
  • Workspaces that start related apps in order.
  • Git branch and changes on every card, with Pull & restart.
  • Databases & services: PostgreSQL, MySQL/MariaDB, Redis, MongoDB, Mailpit.

Share

  • Public links through free Cloudflare Quick Tunnels, with optional password and expiry.
  • Phone preview on your Wi-Fi with QR codes.

Fix

  • Crash fixer: plain-language causes and one-click fixes, offline.
  • Optional AI assistant for Claude Code users.

Everywhere

  • macOS, Windows and Linux, with start-at-login scripts for each.
