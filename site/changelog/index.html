Changelog

New features and fixes in Homeport. Follow along on GitHub.

v1.3.0November 18, 2026

Your own domain, and a Restart Homeport button

Reach Homeport and your apps through your own domain, and restart Homeport in one click when something gets stuck.

New

  • Your domain: Settings → Sharing → Your domain serves the dashboard at home.<domain> and apps at <app>.<domain>, behind a Cloudflare Tunnel and Access login.
  • Restart Homeport: the Restart button in the top bar (also in the sidebar and ⌘K → Restart Homeport) stops Homeport and starts it again. The apps that were running start again with it, and the dashboard reloads by itself. It works however Homeport was started, including the login service.
  • Stop all sits next to Add app whenever an app is running.

Improved

  • The website and docs now cover your domain, Restart Homeport, WordPress, update notices, pull request previews and local HTTPS, and the home page shows the people who build Homeport.

Fixed

  • Opening an app no longer opens two tabs.

Thanks to @sabbirahmad00521 for your domain, Restart Homeport and Stop all.

v1.2.0November 17, 2026

Team setup in one file, pull request previews, and local HTTPS

Share your whole setup with a homeport.json, run a pull request next to your own copy, open apps at https://app.localhost, and pick Gemini through Google Antigravity.

New

  • homeport.json team setup: one file in a repo describes its apps, databases and start order. Add app, Discover projects and Add from GitHub notice it and set everything up in one click — after showing you every command it will run. Save any category as homeport.json from its heading.
  • Pull request previews: on an app from GitHub, ⋯ → Pull requests → Preview runs the pull request in its own folder on its own port, so your work is never touched. Share the preview on the pull request, and remove it when you're done.
  • Comments → GitHub issues: turn a visitor's comment into an issue with the page, screen size and thread filled in. You see the issue before it's created.
  • Notifications for new comments: a desktop notification when a visitor comments or replies on a shared link (Settings → Sharing & feedback).
  • Local HTTPS: Settings → General → Set up HTTPS makes Homeport's own certificate and asks your system to trust it once. Then apps open at https://<app>.localhost — all of them, or per app in Edit — with no change to the app. The certificate only works for localhost names and never leaves your computer.
  • Antigravity (Gemini): Ask AI can use Google Antigravity's agy with your own Google account and Gemini models. If it isn't installed, Homeport shows how to get it.
  • Welcome: a three-step start when Homeport has no apps yet — add your projects, connect GitHub, pick your AI. Reopen it any time from ⌘K → Getting started.
  • Group menu: group apps by category, status, type or folder, with start-all and stop-all on every section.

Improved

  • Wider, cleaner app cards: the description on its own row and a footer with the address (or type and port) and the buttons.
  • The Mac app's title bar takes Homeport's own colours and dims with dialogs, so it no longer looks like a browser frame.
  • Only the apps panel scrolls; the sidebar stays put.
  • Every icon button shows a label on hover, in the desktop app too.
  • Windows: choosing a folder opens the full Explorer-style picker instead of the small folder tree.

Fixed

  • Your old “group by category” choice carries over to the new Group menu.
  • Very long requests to the assistant get a clear message instead of failing on Windows' command-line limit.
v1.1.0November 14, 2026

GitHub, comments on shared links, and a free local AI

Clone and run your repos in one click, collect Figma-style feedback on the live site, and fix crashes with an AI that runs on your computer.

New

  • GitHub: Connect GitHub in one click, then Add from GitHub clones a repo, works out how to run it and starts it. Cards show the CI result next to the branch (main ✓ / ✗), and the menu opens the repo and its pull requests. Private repos work too; your login stays on your computer.
  • Comments on shared links: turn on visitor feedback when you share. Visitors press C, click a spot and comment — pins stay on their spot while scrolling, with replies, a comments panel and hover previews. You read, reply and resolve them in Homeport, or view the site with or without comments.
  • Local AI: besides Claude Code, Ask AI can use a free open model (Qwen, Llama, Gemma) through Ollama — offline, nothing leaves your computer. It follows built-in fix guides, and every change asks you first.
  • Update notices: Homeport now tells you when a newer version is out — a small notice in the sidebar with what's new and a one-click download. It checks GitHub once a day and can be turned off in Settings.
  • Settings: theme (System / Light / Dark), open apps when they start, keyboard shortcuts, AI and model choice, model downloads, GitHub, default share-link expiry and more.

Improved

  • Simpler app cards: status, uptime and branch; the app's address on its own line; sharing as one line with a menu; clear Open and Start buttons. CPU and memory are in the status tooltip and the list view.
  • The sidebar is grouped: your apps, categories, tools, then Settings at the bottom.
  • The ⋯ menu starts with Open, Copy link and Feedback, and opens toward the side with more room.
  • Links on cards open reliably in the desktop app.
  • Installs from source now use the latest release instead of unreleased code.

Fixed

  • Kill & start now waits until the old program has let go of the port, instead of starting too early and crashing on slow computers.
  • Shared pages are never shown from the browser's cache, so turning feedback on or off shows on the next reload.
  • The share-link password page uses the right font.

v1.0.0November 13, 2026

First release

Every local project, one home: free, open source (MIT), no account, on macOS, Windows and Linux.

Install

  • Desktop app: .dmg for macOS, Setup.exe for Windows, AppImage and .deb for Linux. The website's download button picks the right one.
  • One-line terminal install for macOS, Linux and Windows, or run from source with run.command / run.bat / run.sh. Nothing to install first: Homeport brings its own Python if needed.

Run anything

  • Detects how to run Laravel, PHP, WordPress, Django, FastAPI, Flask, Streamlit, Node (Vite, Next, Nuxt, Astro…), Rails, Go, Rust, Spring Boot, .NET, Docker Compose, static sites and more.
  • Add a single file (.html, .php, .js, .py), one project, or a folder of projects at once, each on its own port.
  • Starting an app opens it in a new tab as soon as it responds.
  • Community recipes: support new frameworks with one JSON file.

Use

  • Command palette (⌘K / Ctrl K) for every action.
  • Named URLs like http://shop.localhost:7777, with live reload.
  • Workspaces that start related apps in order.
  • Git branch and changes on every card, with Pull & restart.
  • Databases & services: PostgreSQL, MySQL/MariaDB, Redis, MongoDB, Mailpit.
  • WordPress mode: database, wp-config.php and .sql imports in one place.

Share

  • Public links through free Cloudflare Quick Tunnels, with optional password and expiry. Pages, redirects and links are fixed up so every framework works for visitors.
  • Phone preview on your Wi-Fi with QR codes.

Fix

  • Crash fixer: plain-language causes and one-click fixes, offline.
  • Optional Ask AI side panel for Claude Code users.
