Changelog

New features and fixes in Homeport. Follow along on GitHub.

v1.0.0November 13, 2026

First release

Every local project, one home: free, open source (MIT), no account, on macOS, Windows and Linux.

Install

  • Desktop app: .dmg for macOS, Setup.exe for Windows, AppImage and .deb for Linux. The website's download button picks the right one.
  • One-line terminal install for macOS, Linux and Windows, or run from source with run.command / run.bat / run.sh. Nothing to install first: Homeport brings its own Python if needed.

Run anything

  • Detects how to run Laravel, PHP, WordPress, Django, FastAPI, Flask, Streamlit, Node (Vite, Next, Nuxt, Astro…), Rails, Go, Rust, Spring Boot, .NET, Docker Compose, static sites and more.
  • Add a single file (.html, .php, .js, .py), one project, or a folder of projects at once, each on its own port.
  • Starting an app opens it in a new tab as soon as it responds.
  • Community recipes: support new frameworks with one JSON file.

Use

  • Command palette (⌘K / Ctrl K) for every action.
  • Named URLs like http://shop.localhost:7777, with live reload.
  • Workspaces that start related apps in order.
  • Git branch and changes on every card, with Pull & restart.
  • Databases & services: PostgreSQL, MySQL/MariaDB, Redis, MongoDB, Mailpit.
  • WordPress mode: database, wp-config.php and .sql imports in one place.

Share

  • Public links through free Cloudflare Quick Tunnels, with optional password and expiry. Pages, redirects and links are fixed up so every framework works for visitors.
  • Phone preview on your Wi-Fi with QR codes.

Fix

  • Crash fixer: plain-language causes and one-click fixes, offline.
  • Optional Ask AI side panel for Claude Code users.
