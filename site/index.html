Features

Everything your local stack needs.Nothing it doesn't.

No config files, no accounts. Point Homeport at a folder and it does the rest.

It works out how to run your project.

Pick a folder — or a whole ~/Projects directory — and Homeport detects the framework, package manager, virtualenv and a free port.

  • Installs missing dependencies on first start
  • Named URLs: shop.localhost:7777 instead of port numbers
  • Workspaces start API → frontend → worker in order

Questions

Is Homeport really free?

Yes. It's open source under the MIT license, needs no account and runs entirely on your computer. Public share links use Cloudflare's free, account-less Quick Tunnels.

Do I need to install Python or anything else first?

No. The launcher uses Python if you have it; if not, it downloads a private copy into the Homeport folder — no admin rights, nothing system-wide. Your own projects still use their own tools (Node, PHP, …).

Which systems does it run on?

macOS, Windows and Linux. Double-click run.command on macOS, run.bat on Windows, or run ./run.sh on Linux.

Can other people on my network control my apps?

No. The dashboard only listens on your own computer. Phone preview exposes just the one app you choose, on your local network, until you turn it off.

How do share links stay safe?

You can add a password (only a salted hash is kept) and an expiry. Links also close when you stop sharing, stop the app or quit Homeport.

My framework isn't detected. What now?

Type your start command once — Homeport remembers it. Or add a small JSON recipe so it's detected for everyone; see the docs.
