# Security

Homeport runs on your computer and controls local processes, so security
reports are taken seriously.

**Please don't open a public issue for security problems.** Use GitHub's
"Report a vulnerability" (Security tab → Advisories) on this repository.

In scope, for example:

- anything that lets another device or website control the dashboard
  (it must only be reachable on `127.0.0.1`);
- bypassing the password on protected share links;
- getting the crash fixer, recipes or API to run commands they shouldn't.
